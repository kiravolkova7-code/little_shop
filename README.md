# Little Shop
## Описание
Простое одностраничное веб-приложение на чистом `Python` (библиотека `http.server`) для демонстрации продажи 
породистых котят. Приложение служит учебным примером создания бэкенда, отдающего `HTML`-контент и обрабатывающего 
`POST`-запросы от контактных форм.
Проект имитирует работу небольшого питомника. Пользователь может просматривать информацию о животных, изучать 
каталог пород и отправлять сообщения владельцам через форму обратной связи. Весь интерфейс построен на базе 
фреймворка `Bootstrap 5`, что обеспечивает адаптивность под мобильные устройства.

## Функционал
*   Адаптивная верстка страниц (Главная, Каталог, Контакты) с использованием `Bootstrap Grid`.
*   Отображение карточек товаров (котят) с ценами и описаниями.
*   Фиксированное боковое меню навигации с выпадающим профилем пользователя.
*   Форма обратной связи с полями для имени, электронной почты и текста сообщения.
*   Обработка `GET`-запросов: возврат `HTML`-страницы «Контакты» для любого маршрута.
*   Обработка `POST`-запросов: прием данных формы, их парсинг и печать содержимого в консоль сервера.
*   Динамическое подтверждение успешной отправки сообщения с обращением к пользователю по имени.

## Установка
1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/kiravolkova7-code/little_shop.git

2. Убедитесь, что структура папок соответствует путям в коде (наличие директории templates с файлом contacts.html).
3. Запустите сервер из корневой директории проекта:
```
python main.py
```
4. Откройте браузер и перейдите по адресу `http://localhost:8000`.

## Зависимости
Для запуска приложения не требуется установка сторонних пакетов через `pip`. 
Проект использует исключительно стандартную библиотеку `Python`:
`http.server`, 
`urllib.parse`

## Использование
Приложение работает сразу после запуска скрипта `main.py`. 

* Просмотр сайта: Просто откройте указанный адрес в браузере. По умолчанию сервер вернет страницу контактов.
* Отправка сообщения: Заполните поля «Имя», «Почта» и «Сообщение» в форме на странице контактов и нажмите кнопку «Отправить».
* Проверка данных: Вся информация, введенная пользователем в форму, будет выведена в терминал (консоль), где запущен скрипт сервера, в формате:
```
--- Получен новый POST-запрос ---
Имя: Иван
Почта: ivan@example.com
Сообщение: Хочу купить котенка!
Сырые данные: username=Иван&email=ivan%40example.
com&message=%D0%A5%D
```
